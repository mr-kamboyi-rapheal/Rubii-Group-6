# Visual assets (SCH-XX)

- `favicon.svg` - add to <head>: `<link rel="icon" href="assets/favicon.svg" type="image/svg+xml">`
- `images/logo.svg` - header logo (ScanIn - QR attendance for campus)
- `images/hero-illustration.svg` - hero section image
- `icons/*.svg` - 24x24 line icons; use inline or as <img>. Inline SVG picks up `color` via currentColor.

Palette: #1E3A8A primary, #14B8A6 accent, #F8FAFC background, #0F172A text, #64748B muted.
